# Login & Registration System in C++

## About the Project
This project is a simple Login and Registration System developed in C++ as part of my CodeAlpha internship.

It allows users to register with a username and password, prevents duplicate usernames, and verifies credentials during login using file handling.

## Features
- User Registration
- Duplicate Username Prevention
- Login Authentication
- Invalid Credentials Handling
- File Handling using `users.txt`
- Menu-driven Interface
- Exit Option

## Technologies Used
- C++
- File Handling (`ifstream`, `ofstream`)
- Standard Libraries: `iostream`, `fstream`, `string`

## How to Run
1. Download or clone this repository.
2. Open `LoginSystem.cpp` in a C++ IDE, such as Dev-C++.
3. Compile and run the program.
4. Select an option from the menu:
   - `1` — Register
   - `2` — Login
   - `3` — Exit
